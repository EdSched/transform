## 一句话原则

**课程的一切调整（新增、改日期、改时间、休讲、换老师）只在管理端「课程安排」里做。总务只管教室。教室实在排不了，总务会把情况"反馈"回来，由你在课程安排里改日期或时间。**

不要自己去排课系统里改课程；也不要在排课系统里找「改时间 / 休讲」——总务的账号里已经没有这两个按钮了。

## 场景一：新增一门需要排教室的班课（大课）

### 步骤

1. 管理端 → **课程安排** → 右上角 **＋ 手动添加**（系列课点 **＋ 新建系列课**；已有一期想照抄点课程卡片上的复制到下一期）。
2. 填课程信息：课程名、老师、专业、**校区**、**上课星期**、**开课日 / 结课日 / 回数**、**上课时间**、**预估人数**。
   - 校区和预估人数很重要：总务排教室时按"同校区、容量够"挑教室。
3. 点保存。系统弹出 **「课程已建立，请核对」**窗口，列出每一回的日期、跳过了哪些假期。核对没问题关掉。
4. 到这里**课程已建好，但还没有教室**。课程安排里这门课的卡片标题处会有一行小字 **「未排教室」**。
5. **通知总务排教室。** 现在系统**不会**在新增课程时自动弹教室窗口，也不会自动发消息给总务；总务那边靠首页的"排课提醒"，开课前 45 天内才会出现，写法是：
   - `【2026年…】距开课约 N 天，有 N 门课未排教室，请及时安排。`
   - 距开课 15 天内：`距开课仅 N 天，还有 N 门课未排教室，请于开课前完成！`
   - 已开课：`已开课，仍有 N 门课未排教室，请尽快补排！`
   - **所以新增班课后，建议你直接告诉总务一声。**（待 Sensis 确认：要不要做成"新增班课时自动通知总务"。）
6. 总务在排课系统「排教室」里给这门课选教室，选好后：
   - 课程安排里这门课卡片上的"未排教室"变成教室名（如 **高马 E**）；
   - 每一回的格子下面不再有 `⚠ 未排教室`。
7. **线上课 / 带腾讯会议的课**：教室之外，总务还要在排课系统「会议链接设定」里绑会议账号。总务首页会提示 `还有 N 门已排教室但未设会议链接（含线上课）。`
8. 学生课表：课程建好后要在 **发布管理** 里发布，学生才看得到。（待 Sensis 确认：发布规则以实际为准。）

## 场景二：调整某一回（改日期 / 改时间 / 休讲 / 换老师）

### 2-A　这一回改到别的日期或时间

1. 课程安排里找到那门课、那一回的格子，点格子上的小按钮 **⇄**（提示文字"调整日期"）。
2. 弹出 **「休讲调整」**，上面选 **「改到别的日期」**（不是"休讲并顺延"）。
3. 填新日期、新时间、原因，点 **确认改日期**。
4. 系统接着会弹出两个窗口（一前一后）：
   - **「课程已修改，请核对」**：写着 `第 N 回 11/16 → 11/23 16:00-17:30（原因）`，并提醒 `单回日期有变动（改期 / 休讲顺延 / 新增课次），可能影响腾讯会议安排，请到排课系统确认`。
   - **教室确认**（见下面 ①②）。
5. **教室确认有两种结果：**
   - ① **新日子原教室空着**：不弹窗，页面最上面浮出一行绿条：`已改：第 6 回 → 11/23（一）16:00，原教室 高马 E 空着 ✓`。什么都不用做。
   - ② **原教室被占 / 这门课还没排教室**：弹出 **「这几回的教室需要处理」**，每一回一行：
     - `教室 E　被《XXX》（老师名，15:00-17:00）占着` 或 `这门课还没排教室`；
     - 下面一排教室小标签，`✓` 开头的是空教室，**点一间**，系统问 `第 6 回 11/23 改在 高马 F？`，确认就换好；
     - 想让总务处理：点 **交给总务**（右侧按钮）；一次交给总务全部：**全部交给总务**；
     - 想先放着，等另一门课调整后再说：**稍后调整另一门**（页面上方会留一条黄色提示，冲突消失后自动消失）；
     - 都处理完点 **完成**。**没处理的回保持原样**，课程安排里会显示 `被占 / 未排教室`。
6. **交给总务之后**：总务首页会出现 **「需要协调教室」** 卡片，写明：`【课程名】需要安排教室　你(调整人) 在「课程安排」里改了日期 / 时间 … 第 6 回 → 11/23（一）16:00-17:30　需要的教室 E 在这个时间被「XXX」占着　你要做的：给这 N 回安排教室`。同一门课、同一回不管你改几次日期，**只会留一条**（以最后一次为准）。
7. 课程安排页顶部会出现一个 **「教室协调」**框：`… 等总务处理`；总务处理好后变成绿色 `✓ 11/23（一） 第 6 回 → 高马 F（总务 xxx，11/20）`，保留 7 天。

### 2-B　休讲

1. 同样点 **⇄** → 「休讲调整」，选 **休讲并顺延**。
2. 填 **补课日期**、**补课时间**，点 **确认休讲并顺延**：这一天标为休讲，后面每一回内容依次顺延，末尾补一回。
3. 之后同样会弹「课程已修改，请核对」和教室确认（休讲那天不用教室；补课那一回要查教室）。
4. 想撤回休讲：点那一回的撤回（提示文字"撤回休讲"，弹窗里写着 `这天恢复上课，之后每一回的内容整体前移一位…`）。

### 2-C　整体改上课时间

1. 课程卡片 **编辑** → 改 **上课时间** → 保存。
2. 提示：`上课时间改为 18:30-21:30：今天以后的 N 回已跟着改。以下 N 回单独调整过，保留原样：…`。
3. 若这门课已经排过教室，还会在核对窗口里黄字提示：`课程时间改成 … 了，排课里的每周教室占用还是 …，请到排课调整`。→ **请告诉总务**，让总务检查教室。（待 Sensis 确认：整体改时间后是否也会弹教室确认窗口，我没有在代码里完全确认。）

### 2-D　换老师

1. 课程卡片 **编辑** → 改老师 → 保存。
2. 如果这门课每回老师不一样，会弹：`上课老师已改，请在单回明细里重新分配老师（按周几 / 回数分配，或者去排课）`。→ 在编辑窗口的 **单回明细** 里逐回改。
3. 换老师不影响教室。（待 Sensis 确认：单回换老师的具体点击位置，我没有逐一核对。）

## 场景三：收到「无法安排教室」的反馈

总务按"先推荐空教室、一次换好"处理。**所有教室都排不了**时，总务会点「无法安排教室，反馈给老师」。

### 你会看到什么

课程安排页**顶部**的「教室协调」框里出现红色一块：

> **「经营学专业课面谈」第 6 回 11/23（一）16:00 无法安排教室**（教室 E 被「XXX」占用）。可改为：当天 14:00-15:30 / 15:30-17:00；11/24（二）同时段；换到 市谷 校区。请在课程安排里调整日期或时间（改好后这条提示会自动消失）。　总务名 反馈

框的标题行会写 `需要你调整 N`。

### 怎么用里面的建议

- **当天 14:00-15:30**：同一天，换个时间段（建议是按离原时间最近排的，最多 3 个）。
- **11/24（二）同时段**：换一天，时间不变（只列今天以后、这门课自己没课的日子，最多 3 个）。
- **换到 市谷 校区**：换校区上课（这要和学生、老师确认后再改；校区在编辑课程里改）。
- 建议只是"那个时间有空教室"，不保证老师、学生都方便，**最后由你决定**。

### 怎么改

按场景二 2-A：点那一回的 ⇄ → 改到别的日期 → 填新日期 / 时间 → 确认改日期。再按教室确认窗口提示处理（选空教室，或再交给总务）。

### 提示怎么消失

**不用手动点**。系统以"那一回现在是不是已有教室、教室还有没有被占"为准：
- 你把这一回改到了别的日期或时间 → 刷新课程安排页，提示自动消失；
- 或者总务腾出了教室 / 别的课挪走了 → 同样自动消失。

总务那边：这条卡片先变成灰色 `已反馈给老师，等待调整`，不再算待处理；你改完后，总务首页上这一回自动回到 `需要安排教室`（还没教室）或自动消失（已经有教室）。

## 常见问题

**1. 教室被"以前的占用"挡住了怎么办？**
总务首页的卡片会明说：`这是「XXX」以前留下的占用，它这天已经没有课（11/23）`，旁边有 **清理这门课的遗留占用** 按钮。**这个请交给总务清理**，你不要自己去排课系统里删。（系统现在也会在你改期 / 休讲 / 撤回时，自动清掉原来那天留下的临时占用，以后会少很多。）

**2. 改了课程，为什么教室看板没变？**
- 教室看板 / 今日页每 **5 分钟**自动刷新一次，刷新页面立刻更新；
- 课程安排页里每回的教室标签，同一分钟内重复进入可能不重新读（约 20 秒）；
- 课程表（排课系统的课表格子）**不按每一回的改动画格子**，只在「生成调整说明」里写（待确认这是不是有意）。

**3. 我点了「交给总务」，怎么知道总务处理了？**
课程安排页顶部「教室协调」框：`等总务处理` → 总务处理后变成绿色 `✓ … → 高马 F（总务 xxx，日期）`，保留 7 天。如果总务排不了，会变成红色的"无法安排教室"反馈（场景三）。

**4. 同一回我改了两次日期，总务会收到两条吗？**
不会。同一门课的同一回只保留最新一条；总务首页同一门课的多回会合成一张卡。

**5. 谁该联系谁？**
- 教室被占、没教室、遗留占用、会议链接 → **总务**；
- 总务反馈"无法安排教室" → **你自己**在课程安排里改日期 / 时间；
- 页面报错、数据明显不对（比如课程安排和教室看板对不上）→ **管理员（Sensis）**。
